## Component repositories
### MIP Version 8.5

These are the repositories with all the independent components that MIP is composed of:
- The "MIP Infrastructure", MIP KaaS deployment infrastructure repo based on ArgoCD deployments [https://github.com/Medical-Informatics-Platform/mip-infra](https://github.com/Medical-Informatics-Platform/mip-infra)
- The "Deployment Stack", which enable the installation of the MIP both locally and in a federation [https://github.com/HBPMedical/mip-deployment/tree/8.5.0](https://github.com/HBPMedical/mip-deployment/tree/8.5.0)
- The "Web App" is the interface of MIP: [https://github.com/HBPMedical/portal-frontend/tree/10.0.1](https://github.com/HBPMedical/portal-frontend/tree/10.0.1) 
- The "Backend API" supports the Web App : [https://github.com/HBPMedical/portal-backend/tree/8.2.0](https://github.com/HBPMedical/portal-backend/tree/8.2.0) 
- The "Exareme2 Analysis Engine" offers federated analysis capabilities, supporting SMPC and DP: [https://github.com/madgik/Exareme2/tree/0.28.0](https://github.com/madgik/Exareme2/tree/0.28.0)
- Gateway: middleware layer between the MIP Frontend and a federated analytics engine [https://github.com/HBPMedical/gateway/tree/1.8.0](https://github.com/HBPMedical/gateway/tree/1.8.0)

#### Additional Standalone Tools:
